历史行情回放与交易训练工具 —— 把行情当录像看，在上面反复练手。

## 下载与安装

到 [GitHub Releases](https://github.com/liudosen/TraderRewind/releases) 或
[码云 Releases](https://gitee.com/liudosen/TraderRewind/releases) 下载对应文件，
不需要装 Node、不需要配环境。

| 文件 | 适用场景 | 怎么用 |
| --- | --- | --- |
| `TraderRewind-<版本>-setup.exe` | 想正常装到电脑上 | 双击安装，可自选安装目录；装完从开始菜单启动 |
| `TraderRewind-<版本>-x64.zip` | 不想装、想放 U 盘带走 | 解压到任意目录，双击里面的 `TraderRewind.exe` |

**系统要求**：Windows 10 / 11（64 位）。macOS 与 Linux 需要从源码构建，见[开发与构建](#开发与构建)。

安装包未做代码签名，首次运行时 Windows SmartScreen 可能提示「已保护你的电脑」，
点「更多信息 → 仍要运行」即可。

**应用内更新会自动选快的线路**：同时查 GitHub 与码云两边的发布信息，各测一段速度，
哪边快从哪边下；某条线中途断了会自动换另一条。设置页会显示这次走的是哪条线、
两边各多快。国内直连 GitHub 常常只有几十 KB/s，这条路径基本都会落到码云上。

## 它解决什么问题

复盘时最常见的困境是：**你已经在心里知道后面怎么走了**。
对着完整的历史图表回看，人很容易产生「这里明明该做多」的错觉，实际交易时却根本反应不过来。

TraderRewind 的做法是把行情遮住，只让你一根一根往前推：

- 每一根 K 线都要你自己决定「现在做不做、做多做空、止损放哪」
- 平仓之后才能看到后面的走势
- 一笔一笔积累成训练集，最后用报告告诉你胜率、盈亏比、最大回撤到底是多少

**和「回测」的区别**：回测是让程序按规则跑，这里是让你自己按判断跑。它训练的是你的手，不是策略代码。

## 功能详解

### 一、训练回放

**逐根推进，不给反悔的机会**

- 播放 / 暂停，倍速 1x / 2x / 5x / 10x
- 单步前进（`Shift + →`）；**刻意不提供「上一根」**，进度条也只能往前拖 ——
  已经发生的行情不能反悔，这是训练和自欺的分界线
- 进度条可拖到任意位置，随时跳转

**多周期随时切换**

M1 / M5 / M15 / M30 / H1 / H4 / D1 / W1 / MN1 九个周期一键切换，还能自定义周期。

切换后图表会停在**原来的时间位置**，不会跳回开头。所有周期都由 1 分钟数据实时汇总，
所以 M5 上的那根阳线和 M1 上对应的 5 根不会互相矛盾 —— 跨周期对照时才站得住。

**训练会话**

新建会话时依次选择：

| 设置项 | 说明 |
|---|---|
| 标的 | 从已下载的数据集里选，可用时间范围会跟着显示 |
| 回测时间范围 | 受该标的实际数据范围约束，选不到没有数据的日期 |
| 初始显示周期 | 进图表后默认看哪个周期，进去还能再切 |
| 会话名称 | 可留空，留空时自动按「品种 + 区间」命名 |
| 单笔风险 | 定义 1R 等于多少钱，报告的盈亏、回撤都以 R 计 |
| 交易时段 | 可以限制只在某几个小时开仓，「全天不限」则任何时候都能下单 |

会话会自动保存进度、余额、当前 K 线位置和所选周期，关掉软件下次打开能接着练。

**会话管理**

- 列表可一键隐藏（右上角 `«`），隐藏后图表占满整个宽度，右侧 `»` 随时恢复
- 删除会话需要点两次垃圾桶确认
- **重置**：回到回测起点并清空全部订单，余额复位；画线会保留
- 关闭会话：回到会话列表，数据不丢

### 二、图表与画线

**十一件画图工具**

趋势线、射线、延长线、水平线、垂直线、折线、斐波那契回撤、矩形、椭圆、箭头、文本。

- 两点工具的操作是「左键点起点 → 移动预览 → 左键点终点」，和主流看盘软件一致
- 画完可以拖动端点、整体平移；选中后按 `Delete` 删除
- 一键「清除全部画线」
- **画线随会话保存**，下次打开还在

**十字线与光标**

十字线可吸附到 K 线（默认关闭，跟随鼠标自由移动），可开关价格标签。

### 三、技术指标

| 位置 | 指标 |
|---|---|
| 主图叠加 | EMA 均线、BOLL 布林带 |
| 副图 | 成交量、MACD、RSI、KDJ、CCI、ATR、OBV |

- 主图叠加可以**重复添加**（比如同时挂 EMA12 和 EMA60）
- 副图最多同时开 4 个
- 加完之后在 K 线左上角点指标名就能改参数，参数随会话保存

### 四、模拟下单与风控

**下单**

- 买入 / 卖出两个按钮，价格就是当前 K 线收盘价
- 手数以 0.01 为步进；按住 `Shift` 调手数则每次 ±0.1
- 可以手动平仓，也可以「全部平仓」一次清掉所有持仓

**开仓备注**

点买入 / 卖出会弹出备注浮窗，记录这笔单子的思路，还能打标签
（左中左 / 左中右 / 右中左 / 右中右 / 震荡 / 弱趋势 / 次强趋势 / 强趋势，标签可自定义）。

急着下单可以点「跳过并下单」，也可以再按一次 `B` / `S` 直接成交 —— 备注不抢焦点。

备注和标签会写进成交记录，复盘时能看到「当时为什么这么做」。

**可拖拽的止损止盈**

入场后图上会出现入场线（灰）。按住这条线上下拖动，就会把它拆成止损线和止盈线：

- 向上拖 = 止盈，向下拖 = 止损
- 买多时自动限制在入场价上方的止盈、下方的止损，拖错方向会被挡回去
- 拖着走的价格标签实时显示距离入场价多少个点

**自动平仓判定**

回放逐根推进时，只要这一根 K 线触及止损或止盈就立即成交。

单根 K 线只能看到开高低收，还原不了盘中到底是先摸高点还是先砸低点。
所以采用**保守规则：同时触及时先判止损** —— 宁可少给你一次侥幸。

**合约规格**

每笔单子的盈亏计算会参考该品种的合约规格（1 手 = 多少单位 / 盎司 / 币）、
小数位数、每点价值和杠杆（默认 1:500），下单前就能看到「$0.0100 每点盈亏 · 100 盎司 1 手规模」。

### 五、训练报告与复盘

训练走到末尾会自动弹出报告，也可以随时点「报告」查看当前进度。

**核心指标**

| 指标 | 含义 |
|---|---|
| 总收益（R） | 以 R 为单位的总盈亏，1R = 你设置的「单笔风险」金额 |
| 平均每单 | 每笔的平均 R 值 |
| 胜率 | 盈利笔数 / 总笔数 |
| 盈亏比 | 平均盈利 ÷ 平均亏损 |
| 最大回撤 | 权益曲线从峰到谷的最大跌幅，同时给出 R 值和百分比 |

**R 收益曲线**

按平仓顺序逐笔累加的权益曲线，能直观看到「前面赚的后面又送回去了」。

**逐笔明细**

每一行包含开仓 / 平仓时间、方向、手数、入场价、出场价、R 值、平仓原因
（手动 / 止损 / 止盈）、标签、盈亏金额和备注。

**点任意一笔，图表会跳到那根 K 线并画出这笔的开仓线和关仓线** ——
这是复盘最常用的动作：回看这笔到底错在哪。

明细上方有标签筛选条，可以按标签过滤（比如只看「强趋势」下的表现）。
支持多选，多个标签之间是「且」——一笔交易要同时带上所有选中的标签才留下，
所以「右中右」+「次强趋势」能筛出「位置在右中右、且趋势次强」的那几笔。

**训练参数留档**

每次训练的全部设置都会存下来：用了哪个数据集、回放区间多长、初始资金、默认手数、
单笔风险、交易时段、主副图指标、画线数量、成本模型、训练用时、完成时间。

过一段时间回头看，你还能还原出「当时是在什么条件下做的这笔训练」。

### 六、数据源与下载

**两个来源：你的经纪商，或公开加密接口**

| 数据源 | 类型 | 品种数 | 说明 |
|---|---|---|---|
| cTrader | 1 分钟 K 线 | 193（随经纪商） | 直连本机 cTrader 桌面端内置的行情服务，取你自己经纪商的真实报价；走本地回环，不用代理 |
| OKX | 1 分钟 K 线 | 12 | 现货 USDT 计价主流币，接口直接返回蜡烛，无需聚合 |
| Binance | 1 分钟 K 线 | 12 | 同上，走 `data-api.binance.vision` 公共行情端点 |

> 早期版本的 Dukascopy 逐笔 tick 通道已在 0.3.0 下线：数据质量与下载速度都不如直接取经纪商报价。

**cTrader 怎么连上**

1. 装好 [cTrader 桌面端](https://www.ic.com/en/forex-trading-platform-ctrader/ctrader-windows) 并登录经纪商账户；
2. 在 cTrader 里打开 `设置 → 应用程序 → MCP 设置 → 启用 MCP 服务器`（默认端口 9876）；
3. 回到本软件，数据源面板的状态灯变绿即表示连通，品种表会自动换成经纪商的全部品种。

没有 cTrader 账户可以在面板里直接点「注册 IC Markets」开户。端口可用环境变量
`CTRADER_MCP_PORT` 覆盖。

**MCP 状态灯**

面板上那盏灯每 3 秒探一次本机端口：**绿 = 已连接（附端口与连接耗时）、红 = 端口无响应、
灰 = 正在检测**。探活只做一次 TCP 连接，不建立 MCP 会话 —— 不会占用会话配额，
也不打扰正在跑的下载任务。

**品种表可能"不全"？**

cTrader 的品种归经纪商所有，只有桌面端在跑的时候才拿得到。软件启动时如果 cTrader 还没开，
会先退回内置的 23 个外汇品种并明确提示；等你把 cTrader 打开，状态灯探到之后会**自动补拉**，
也可以随时点「刷新品种」手动重拉（会跳过 60 秒缓存）。

切换数据源会**自动清空已选品种** —— 各家的代码格式完全不同（`EURUSD` / `BTC-USDT` / `BTCUSDT`），
留着旧的选中项只会得到一堆「未知品种」。

**品种列表**

- 按类别分组：主要货币对 / 交叉盘 / 贵金属 / 指数 / 商品 / 股票 / 加密市场 / 其它
- 点表头折叠展开，折叠状态本地记忆，下次进来还是上次的样子
- 表头右侧有一个「选中本组 / 取消本组」按钮，加密一组几十个币种不用一个个点
- 支持按代码或中文名搜索

**下载设置**

- **并发数**：1–64 路（加密接口限速更严，上限 8，实际会被压到 4~6）
- **日期范围**：自研选择器，两步选起止日；可跳年份月份、从「某月 1 日」起选；
  预设最近 3 / 7 / 30 / 90 天；选结束日期时悬停可预览区间；未来日期禁用
- **HTTP 代理**：支持 HTTPS CONNECT 隧道，中国大陆直连境外数据源通常需要

**只下 1 分钟，其余靠聚合**

所有数据源统一只下 M1，5 / 15 / 30 分钟、1 / 4 小时、日线都在绘图时从 1 分钟实时汇总。

好处是**各周期口径完全一致**，你在 M5 上画的东西和 M1 上看到的走势不会打架，
也不会出现「日线数据和分钟数据对不上」这种经典问题。

**增量入库**

同品种同周期复用同一个数据集，重复下载会 `INSERT OR REPLACE` 合并，并重算时间范围。

**已下载的日期会划线禁用**

选中品种后，日历里已经有数据的日期会划线、置灰，对应的预设按钮也不可用；
整段都下过时「开始下载」直接禁用并提示换个范围 —— 避免白跑一次还覆盖不出新数据。

**实时进度**

进度条、瞬时速度、平均速度、剩余时间、已完成文件数 / 总文件数、已解析 K 线根数、已下载字节数。
多品种并行时每个品种一条独立的进度条。

**可取消**：任意时刻中断，已完成的部分不入库。

### 七、数据存储

数据拆成两个独立的 SQLite 库，**目录可以分别指定**：

![数据存储](docs/screenshots/settings-storage.png)

| 类别 | 内容 | 库文件 | 默认位置 |
|---|---|---|---|
| 行情数据 | 分组、数据集、K 线、Tick | `market.db` | `<userData>/data/kline` |
| 训练数据 | 会话、持仓、成交、日志、账户 | `training.db` | `<userData>/data/training` |

- 行情库几十上百 MB、训练库只有几百 KB，分开存之后备份和迁移都方便得多
- 更换目录时，如果新目录还没有同名库文件，会自动把当前的复制过去；已经有则直接切换
- 老版本的单库 `traderrewind.db` 会在首次启动时自动拆分成两个新库，原文件重命名为 `*.migrated`

**导出 / 导入（.db）**

数据集可以整包导出成一个**独立可携带的 sqlite 文件**，发给别人、丢 U 盘、放网盘都行；
拿到文件的人直接导入即可，不需要连你的行情库。

- **导出**：「已下载数据」表格每行一个导出按钮（单个数据集），标题栏「导出全部」一次打包。
  文件里带 `export_meta`（格式标记 / 版本 / 导出时间 / 品种清单），不打开库也知道里面是什么。
- **导入**：可多选文件一起导。按「品种 + 周期 + 来源」合并进已有数据集 ——
  **区间外的新数据追加，同一时间戳的 K 线以导入文件为准覆盖**。重复导入同一个包不会
  多出一份 EURUSD，根数也不会翻倍。
- **坏文件挡在门外**：缺表、格式不认识、包版本比程序新，都会明确报错，而不是把库写坏。
- 搬运走 sqlite 自己的 `ATTACH` + `INSERT ... SELECT`，不经过 JS 循环：
  实测 60 万根（39 MB）导出 0.3 秒、导入 0.5 秒。

### 八、设置项

**通用**

- 数据存放位置（两个库分别设置，可一键打开所在文件夹）
- 主题（暗色）、语言（简体中文 / English）
- 关于：版本号与开源授权

**交易**

- 手续费模型：按手固定金额（如 $3.5/手/边）或按名义价值百分比
- 滑点点数
- 这两项会算进每一笔成交，报告里看到的盈亏是**扣过成本**的真实数字

**图表**

- 四套快速配色：白灰涨跌（默认）/ 红涨绿跌（中国习惯）/ 绿涨红跌（欧美习惯）/ 浅色背景 / 深色背景
- 逐项自定义：上涨色、下跌色、图表背景、坐标文字、网格线颜色与显隐
- 十字线：颜色、线型（实线 / 点线 / 虚线 / 长虚线 / 稀疏点线）、线宽、价格标签开关、吸附到 K 线
- K 线细节：影线、边框显隐
- 改完立即生效，全部存进 `settings.json`，可一键恢复默认

**指标**

- 各指标的默认参数（周期、倍数等），新会话按这里的值初始化

**时区**

- 图表时间轴、成交记录、报告的时间显示时区，内置 UTC+0 到 UTC-8 等常用选项

## 技术栈

| 层 | 技术 | 选它的理由 |
|---|---|---|
| 桌面框架 | Electron 33 + electron-vite | 一套代码跑三平台，主进程能直接读写 SQLite |
| 主进程 | TypeScript + better-sqlite3 | 同步 API 简单直接，几十万根 K 线的读写不卡 |
| 渲染层 | React 18 + Zustand + Tailwind CSS | 状态集中管理，高频进度更新不会带着整棵树重渲染 |
| 图表 | lightweight-charts v5（TradingView） | 体积小、Canvas 渲染、百万级数据量也流畅 |
| 取数 | cTrader 本地 MCP + OKX/Binance 公开接口 | 外汇取你自己经纪商的真实报价，加密取公开行情 |

## 行情数据来源

**cTrader（本机 MCP）**

cTrader 桌面端（5.9+）内置了一个 MCP 服务，软件直接去找它要历史 K 线：

```
http://127.0.0.1:9876/mcp/
```

- 走 JSON-RPC 2.0 over HTTP；工具 `get_trendbars` 就是官方历史 K 线接口
- **单次最多 1000 根**，且返回的是「范围内靠近 `to` 的最后一页」，所以翻页只能从 `to` 往过去倒退
- 时间参数是秒级 ISO（`2024-11-04T23:58:00Z`）；周期写 `m1 / m5 / m15 / m30 / h1 / h4 / d1`，不是分钟数
- 目标是 `127.0.0.1`，**必须直连** —— 套上系统代理会被转发到代理网关而 502
- 服务端同一时刻只认一个会话，且会话不会自动过期；退出前要显式 `DELETE` 释放，
  否则每启动一次就泄漏一个，攒到上限后连握手都会被拒
- 拿不到实时品种表时退回内置清单，界面会明说当前用的是兜底数据

**OKX / Binance**

两家都走公开 K 线接口，用 `1m` 周期分页拉取。它们的翻页方向是**相反的**：
OKX 的 `after` 往更旧的时间走，Binance 的 `startTime` 往更新的时间走。
所以每个适配器各自维护自己的游标逻辑，调度层只认「给定游标拿下一页」这一个抽象。

> 历史版本（≤ 0.2.x）走过 Dukascopy 的 bi5 逐笔 tick，0.3.0 起已下线，
> `src/main/services/bi5.ts` 仅为遗留代码，不参与下载。

> 行情数据版权归各自提供方所有。本项目仅用于个人学习与研究，不构成任何投资建议。

## 开发与构建

需要 Node.js 20 以上。

```bash
npm install           # 安装依赖（postinstall 会自动 rebuild better-sqlite3 匹配 Electron ABI）
npm run dev           # 启动开发环境
npm run typecheck     # 类型检查
npm run build         # 构建到 out/
npm run package:win   # 打 Windows 安装包（NSIS）
npm run package:mac   # 打 macOS dmg
npm run icons         # 由 build/logo.svg 重新生成各尺寸图标
```

> Electron 二进制走国内镜像（见 `.npmrc`）。若安装后报
> `@rollup/rollup-win32-x64-msvc` / `@esbuild/win32-x64` 缺失，补装即可：
> `npm i -D @rollup/rollup-win32-x64-msvc @esbuild/win32-x64`

改动 `src/main/**` 或 `src/preload/**` 后**必须完全退出重开**，这几层不热更新。

更多细节见 [贡献指南](CONTRIBUTING.md)。
